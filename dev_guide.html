THE BACKROOMS featuring HARUKI

モバイル向けのバックルームス系ホラーレイキャスティング FPS。HTML5 Canvas + Web Audio API + Vanilla JS のみ、外部ライブラリなし。タイトル画面、12 レベル、10 種類のエンティティ、13 種類のアイテム、4 段階の難易度、ENDLESS モードを搭載。

コア体験

探索 → ノート発見 → no-clip ポータル発見 → 次階層 → 最終的にエンディング (FRONTROOMS END / HARUKI END / TRUE END)。途中、エンティティが SAN/HP を削る。アイテム/M.E.G. セーフエリア/ミニゲーム/電話 (M.E.G. アプリ) でリソース管理。

ストーリー設計

世界観

主人公が現実世界の壁を no-clip (すり抜け) してバックルームスに迷い込む。各レベルは独立した無限空間。M.E.G. (The Major Explorer Group) が安全地帯を運営。HARUKI は本作固有の追跡型エンティティで、特定レベルで遭遇する元・知人。

イントロ (3 シーン POV カット)

SCENE 1: 夜の路地

街灯が点滅する路地裏を歩く。冷たい風。突然、壁の中に "ノークリップ" する感覚。

SCENE 2: 壁の中

視界が歪み、現実が剥がれていく。黄色い光が見える。

SCENE 3: ロビーへ降臨

気がつくと黄色い壁紙の無限の部屋。ハム音、湿った絨毯。LEVEL 0 開始。

エンディング分岐

  • FRONTROOMS END — LEVEL 9 の THE END 扉に到達。現実への帰還。
  • HARUKI END — LEVEL 5 / 7 で HARUKI に追われ続けると...?
  • TRUE END — 全レベル踏破 + 全ノート発見 + Boss 撃破。

ノート (91 種)

各レベルに散らばっている lore note。読むことで世界観を補完。M.E.G. の生存者ログ、過去の探索者の遺書、HARUKI の手紙など。

イベント順序 (起動 → エンディング)

1. ページロード

init() 実行 → GameEngine 初期化、画像プリロード、LocalStorage ロード、bindEvents() で全 DOM ハンドラ登録、showOverlay('titleScreen')

2. タイトル画面

BGM (classical horror) が初回タッチで開始。ボタン: はじめから / つづきから / フリーローム / ENDLESS / 難易度 / 操作説明 / 設定 / 全データ削除

3. はじめから

イントロシネマ (3 シーン) → setLevel(0) → ローディング画面 → LEVEL 0 開始

4. レベル進入演出

levelReachCinematic オーバーレイ表示 (タップで進む)。レベル名・サブタイトル・ヒント表示。

5. プレイループ (60fps)

onUpdate: 移動・SAN/HP/STA 更新・エンティティ AI・脅威検知 (nearestThreat 計算)・空間音響キュー。
onRender: マップ・エンティティ・ピックアップ・noclip ビーム・暗闇マスク・脅威コンパス。

6. ピックアップ / ノート発見

右上に discoveryPopup 表示。表示中は update が一時停止 (エンティティも止まる)。タップ or 自動消去で再開。

7. no-clip 扉発見

noclip-flash で画面を白くフラッシュ → setLevel(nextId) で次階層へ。

8. エンティティ遭遇

初遭遇時 encounterCinematic で entity 図鑑解放演出。HARUKI 初遭遇では特別なシーン。

9. ダメージ → DEAD

HP 0 で state = DEAD、gameOverScreen 表示。最後のセーブから再開 / タイトルへ。

10. エンディング

LEVEL 9 / 12 / 11 で条件達成 → endingScreen 表示。スコア・タイム・ノート発見率を集計。

  • 画面左半分: 動的ジョイスティック (タップした場所が中心)。ダブルタップで sprint。

更新ルール

このファイルは生きたドキュメントです。 新しいエンティティ・アイテム・レベル・設定・状態を追加したら、必ず該当セクションを更新してください。具体的には:
  • エンティティ追加: エンティティ一覧 + CSS 描画を追加
  • アイテム追加: アイテム一覧 に icon/desc 追加
  • レベル追加: レベル一覧 にカード追加
  • 設定追加: 設定項目 テーブルに行追加
  • イベント追加: イベント順序 の timeline に挿入
監視 (1): watchdog — ~/.local/maintenance/chill_haruking_watchdog.sh。5 分毎に最終 commit timestamp をチェックし、30 分以上 idle で macOS 通知を発火。launchd label: com.local.chill-haruking-watchdog
監視 (2): auditor — ~/.local/maintenance/chill_haruking_auditor.sh。15 分毎にゲーム整合性を検査。チェック項目: ①game.js / engine.js の syntax、②HTML id 整合性 (el('xyz') で参照される ID が HTML に存在するか)、③var-hoist 違反 (UPPERCASE 変数への property assignment が宣言より前にないか)、④cache version 統一、⑤6h+ commit idle、⑥title button ID 存在確認。issue 検出時 macOS 通知。launchd label: com.local.chill-haruking-auditor
★ 教訓 (2026-06-07): var 巻き上げによる IIFE 死亡 — ENTITY_SOUND_MAP.echo = {...} を var ENTITY_SOUND_MAP = {...} より前で実行していた。var は宣言だけ巻き上げられ値は undefined のまま、property access が TypeError を投げて IIFE 全体が停止、bindEvents/init/__titleAction override が動かずタイトルボタンが完全無反応に。auditor で同種パターンを定期検出するようにした。UPPERCASE 定数オブジェクトには初期 literal にすべてのプロパティを書き、後から代入は避ける。
